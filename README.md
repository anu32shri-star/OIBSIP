# 🍔 Swad-Express AI Voice Assistant
*Intelligent food delivery support powered by Gnani AI Prisma & Timbre.*

Built for the **Great Indian AI Internship Challenge**, **Swad-Express** is a production-grade, multilingual voice support bot featuring a modern SaaS-inspired UI. It bridges customer voice queries with automated backend resolution using advanced speech recognition and text-to-speech pipelines.

## 🚀 Key Features & Architecture
* **Frontend:** Voxly-inspired SaaS dashboard built with **Streamlit**, featuring custom lavender/violet styling (`#7165E8`), language selector cards, and live conversation streams.
* **Speech-to-Text (STT):** Integrated with **Gnani Prisma V3.0** to accurately transcribe regional Hindi/Hinglish customer voice notes.
* **Bot Intelligence:** Custom intent-matching logic handling order status and delivery updates.
* **Text-to-Speech (TTS):** Integrated with **Gnani Timbre v2.5** (Nalini voice model) to synthesize natural voice responses back to the user.
